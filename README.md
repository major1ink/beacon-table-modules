# Модули для Beacon Table

Отдельный репозиторий с модулями контента для [Beacon Table](https://github.com/major1ink/Beacon-Table):
игровые системы и карточки к ним. Контент выходит в своём ритме, без обновления
программы: правка правила, нового монстра или заклинания — это новая версия модуля,
а не нового релиза программы.

## Что здесь лежит

| Модуль | Тип | Что внутри |
|---|---|---|
| `dnd5e-2014` | система | схемы листа и карточек, правила боя, монеты и вес, состояния SRD 5.1, импортёры |
| `dnd5e-2024` | система | то же для редакции 2024, состояния SRD 5.2 |
| `dnd5e-2024-srd` | контент | существа, заклинания, предметы и справочник SRD 5.2 (требует `dnd5e-2024`) |
