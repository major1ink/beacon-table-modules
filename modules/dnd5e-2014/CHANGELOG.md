# Изменения

## 1.2.0 — 2026-10-05
Размер токена по карточке: существо ставится на карту на столько клеток, сколько занимает по своей категории размера (Большое — 2×2, Огромное — 3×3, Гигантское — 4×4). Нужна Beacon Table с поддержкой раздела tokenSize; более ранние версии раздел пропускают.

## 1.1.0 — 2026-10-04
Оформление системы: тёмно-бордовый акцент с золотом, тёплые поверхности, шрифт Forum для заголовков, золотые линии на листе и карточках.

## 1.0.1 — 2026-10-04
Убрано поле importers из module.json: импорт Foundry, TTG Club и LSS теперь определяет программа.

## 1.0.0 — 2026-09-30
Первый выпуск в отдельном репозитории модулей: перенос из встроенного каталога Beacon Table 0.8.x. Система D&D 5e (редакция 2014): лист персонажа, карточки существа, заклинания, предмета и справочника на схемах, правила боя, монеты и вес, состояния.
